# Paytm Agent Pay

Built for the Agent Labs Buildathon: Phinite x Paytm (Bengaluru, 12 Sep 2026). Track 1: AI for Paytm Users.

A personal payments agent inside Paytm that discovers merchant agents in the Phinite Agent Registry, gets quotes over A2A, scores every payee for fraud risk, blocks and reports scams, and only pays after the human's explicit approval token.

- `RUNBOOK.md` - step-by-step for build day
- `sandbox/` - mock Paytm backend + live demo page (`npm start`, `npm test`)
- `phinite/` - tools, prompts, Agent Card copy, RAG doc to paste into Phinite
- `PHINITE_KNOWLEDGE_BASE.md` + `research/docs/` - platform reference
