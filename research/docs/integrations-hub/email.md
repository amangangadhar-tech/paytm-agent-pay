# Email (SMTP)

> Send transactional and notification emails using SMTP providers.

<Note>
  These integrations connect to **Agent Graphs** via published tools and workspace **Integrations**. See [Integrations hub overview](/integrations-hub/overview) and [Configure integrations](/configure/integrations).
</Note>

## Overview

Phinite’s Email integration sends transactional and notification emails using your SMTP provider (Gmail, Outlook/Office365, SendGrid, Mailgun, or custom SMTP).
