# Contacting Support

> How to report Agent Graph, tool, and deploy issues and get help.

Before opening a ticket, gather artifacts that map to **Agent Graph** runs—not just Studio drafts.

## Before contacting support

1. Collect [session log](/observability/logs) excerpts or error codes ([reference](/support/error-codes)).
2. Include sample trigger/tool **input** and **expected output**.
3. Specify environment (DEV / UAT / PROD), **Build** version, and channel.
4. Note recent publishes or deploys ([release notes](/reference/release-notes)).
